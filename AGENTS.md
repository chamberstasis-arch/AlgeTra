# Instrucciones para agentes

Este repositorio contiene AlgeTra (MVP de transcripción de álgebra lineal). Si te piden **procesar hojas de libreta** (`trabajo/por_procesar`), tu trabajo está definido en `harness/INSTRUCCIONES.md`: léelo completo y también `harness/APRENDIZAJES.md`. No modifiques código ni `corpus/` salvo que te lo pidan expresamente para desarrollo.
