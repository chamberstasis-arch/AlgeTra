# act-23 — Magnitud y cosenos directores en R3

Resolución de referencia (no mostrar a quien transcribe).

## Ejercicio 1

$$|v|=\sqrt{9}=3$$
$$\cos\alpha=\frac{v_x}{|v|},\ \cos\beta=\frac{v_y}{|v|},\ \cos\gamma=\frac{v_z}{|v|}$$

**Respuesta:** |v| = 3; cos α = 0, cos β = 1, cos γ = 0
$$3$$

## Ejercicio 2

$$|v|=\sqrt{21}=\sqrt{21}$$
$$\cos\alpha=\frac{v_x}{|v|},\ \cos\beta=\frac{v_y}{|v|},\ \cos\gamma=\frac{v_z}{|v|}$$

**Respuesta:** |v| = \sqrt{21}; cos α = \frac{4}{\sqrt{21}}, cos β = -\frac{2}{\sqrt{21}}, cos γ = \frac{1}{\sqrt{21}}
$$\sqrt{21}$$
