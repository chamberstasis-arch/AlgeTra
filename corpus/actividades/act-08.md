## Ejercicio 1

Encuentre todas las soluciones al siguiente sistema homogéneo:
$$\begin{aligned}
2x_{1} - x_{2} &= 0 \\
3x_{1} + 4x_{2} &= 0
\end{aligned}$$

**Respuesta:** x_{1} = 0, x_{2} = 0
$$0$$
$$0$$

## Ejercicio 2

Encuentre todas las soluciones al siguiente sistema homogéneo:
$$\begin{aligned}
x_{1} - 5x_{2} &= 0 \\
-x_{1} + 5x_{2} &= 0
\end{aligned}$$

**Respuesta:** Infinitas soluciones: x_{1} = 5t, x_{2} = t

## Ejercicio 4

Encuentre todas las soluciones al siguiente sistema homogéneo:
$$\begin{aligned}
x_{1} + x_{2} - x_{3} &= 0 \\
2x_{1} - 4x_{2} + 3x_{3} &= 0
\end{aligned}$$

**Respuesta:** Infinitas soluciones: x_{1} = \frac{1}{6}t, x_{2} = \frac{5}{6}t, x_{3} = t
