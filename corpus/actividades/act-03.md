## Ejercicio 1

Resuelva el siguiente sistema de ecuaciones lineales:
$$\begin{aligned}
x - y + z &= 0 \\
2y - z &= 1 \\
3z &= -1
\end{aligned}$$

**Respuesta:** x = \frac{2}{3}, y = \frac{1}{3}, z = -\frac{1}{3}
$$\frac{2}{3}$$
$$\frac{1}{3}$$
$$-\frac{1}{3}$$

## Ejercicio 2

Resuelva el siguiente sistema de ecuaciones lineales:
$$\begin{aligned}
x - 2y - 3z &= 0 \\
-5y + 2z &= 0 \\
4z &= 0
\end{aligned}$$

**Respuesta:** x = 0, y = 0, z = 0
$$0$$
$$0$$
$$0$$

## Ejercicio 3

Resuelva el siguiente sistema de ecuaciones lineales:
$$\begin{aligned}
x_{1} + x_{2} - x_{3} - x_{4} &= 0 \\
x_{2} + x_{3} + x_{4} &= 0 \\
x_{3} - x_{4} &= 0 \\
x_{4} &= 1
\end{aligned}$$

**Respuesta:** x_{1} = 4, x_{2} = -2, x_{3} = 1, x_{4} = 1
$$4$$
$$-2$$
$$1$$
$$1$$

## Ejercicio 4

Resuelva el siguiente sistema de ecuaciones lineales:
$$\begin{aligned}
x - 3y + z &= 5 \\
y - 2z &= -1
\end{aligned}$$

**Respuesta:** Infinitas soluciones: x = 2+5t, y = -1+2t, z = t
