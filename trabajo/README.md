# Carpeta de trabajo del agente

| Carpeta | Contenido |
| --- | --- |
| `por_procesar/` | Aquí dejas las fotos (jpg, png, webp). |
| `en_proceso/` | La hoja que el agente tiene en este momento (una a la vez). |
| `procesadas/` | Hojas cerradas sin pendientes: imagen, `transcripcion.md`, `documento.docx`, `informe.json`. |
| `revision/` | Hojas con `[?]`, dudas o gráficas: necesitan tu mirada. |

El contenido no se versiona (son escritos de terceros). Ver `harness/INSTRUCCIONES.md` y el README principal.
